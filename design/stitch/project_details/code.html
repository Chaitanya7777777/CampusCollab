Smart Traffic Management: Real-Time Green Corridor System

Reducing emergency vehicle dispatch latency across critical urban junctions using roadside edge AI inferencing and adaptive multi-phase traffic signal switching.

Target Junction Latency < 50 ms Edge
Hardware Platform Jetson Nano / ESP32
Team Size Target 3 / 6 Members
Submission Deadline Nov 18, 2025
troubleshoot

Problem Statement & Solution Scope

In metropolitan arterial corridors, emergency medical services (ambulances) and fire rescue vehicles lose up to 14 minutes in congested bottleneck nodes due to uncoordinated, pre-timed signal controllers. Existing GPS solutions lack fine-grained spatial accuracy and struggle inside urban canyons, leading to inaccurate intersection clearance.

Our SIH 2025 architecture pairs high-efficiency roadside camera nodes with ultra-low latency edge vision processing (YOLOv8 nano running on NVIDIA Jetson platforms) alongside direct encrypted 868MHz RFID vehicle beacons. Upon detecting approaching priority transit, signals dynamically adapt their phase windows without disrupting arterial platoon synchronization.
